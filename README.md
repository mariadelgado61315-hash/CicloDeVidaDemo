En este primer proyecto se crea la aplicación CicloDeVidaDemo en Kotlin, con dos intensiones 
1° aprender a utilizar el entorno de trabajo Android Studio  y la 2° entender cómo funciona el ciclo de vida de una pantalla (Activity).
con estas practicas  realmente me comence a relacionar con las  herramientas clave como el emulador, la consola Logcat mediante mensajes Log.d, 
y la integración de Git/GitHub para el control de versiones.
